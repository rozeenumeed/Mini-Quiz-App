# 🎯 Mini Quiz App

A simple and interactive Mini Quiz App built using HTML, CSS, and JavaScript. This project allows users to answer multiple-choice questions, receive instant feedback, and track their scores.

## 🚀 Features

* Multiple-choice questions (MCQs)
* Instant feedback for correct and incorrect answers
* Score tracking
* Next button to navigate between questions
* Final score displayed after completing the quiz
* Simple and user-friendly interface
* Responsive design (if supported by the current CSS)

## 🛠️ Technologies Used

* **HTML5** — Structure of the application
* **CSS3** — Styling and layout
* **JavaScript** — Quiz logic, answer checking, and score calculation

## 📂 Project Structure

## 💻 How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Start answering the quiz questions!
